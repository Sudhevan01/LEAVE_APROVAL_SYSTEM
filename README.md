Leave Approval Management System

A role-based Leave Approval Management System built using Django Framework that streamlines employee leave requests and approval workflows. The system allows employees to apply for leave, track request status, and enables administrators to review, approve, or reject requests through a dedicated dashboard.

🚀 Features
Employee Module
User Registration & Login
Apply for Leave
View Leave History
Track Leave Status (Pending, Approved, Rejected)
Logout Functionality
Admin Module
Secure Admin Login
View All Leave Requests
Approve or Reject Requests
Dashboard Analytics
Search Leave Requests
Leave Statistics Visualization
Additional Features
Role-Based Authentication
Email Notifications for Leave Approval/Rejection
Interactive Charts using Chart.js
Responsive Bootstrap UI
SQLite Database Integration
🛠️ Tech Stack
Backend: Python, Django
Frontend: HTML, CSS, Bootstrap 5
Database: SQLite
Charts: Chart.js
Authentication: Django Authentication System
Email Service: Gmail SMTP
